# Hardware manager

Placeholder for hardware management scripts using Bash and Python 3.12.
Both interpreters are available in the development container.

Use Bash for shell scripts and Python's standard library where sufficient.
If Python dependencies are needed later, declare them in this project and
create a dedicated environment under `~/.venvs/hardware-manager`.
Hardware access is configured through the existing host setup; add device
access when specific hardware requirements are known.
