# Flight visualizer frontend

Placeholder for a Svelte frontend managed with Bun. Bun and Node LTS are
available in the development container.

When scaffolding the application, declare Svelte and the selected build tools
in this project's `package.json`, install them with Bun, and commit `bun.lock`.
For subsequent installs and development, use the project's scripts:

```bash
cd ~/workspace/flight_visualizer/frontend
bun install --frozen-lockfile
bun run dev
```

These commands apply after the application manifest, lockfile, and dev script
are added. No application or Svelte dependencies have been installed yet.
